# GL.iNet GL-AXT1800

## Install OpenWRT

1. Download the latest firmware here - [https://firmware-selector.openwrt.org](https://firmware-selector.openwrt.org)

   Search for AXT1800 to find the firmware.

1. Download the UBI image

1. Follow the instructions here to install - [https://openwrt.org/toh/gl.inet/gl-axt1800](https://openwrt.org/toh/gl.inet/gl-axt1800) 

## Add your public SSH key to the router for passwordless access from your workstation

```bash
cat <PATH_TO_KEY>/ssh_key.pub | ssh root@192.168.1.1 "cat >> /etc/dropbear/authorized_keys"
```

## Configure the wireless network -

1. Log into the Luci inteface at 192.168.1.1

1. Configure a root password for the router

1. Use the network menu to configure the wireless LAN.

1. Delete the existing `Master` network, and create a new one.  Attach the new access point config to the `lan` network.  Enable your choice of wireless security.

1. I recommend connecting the router to your home network via the Wan port for faster connections.  However, if you are planning to use the wireless repeater capabilities of the router, then click `Scan` to add another connection to either of the radios and configure it as a Client connected to your wireless network.

## Make Nginx listen only on the main interface.  For a 3 node cluster Nginx will be listening on a new interface with a stream configuration.

```bash
uci del_list nginx._lan.listen='80'
uci del_list nginx._lan.listen='[::]:80'
uci del_list nginx._lan.listen='443 ssl'
uci del_list nginx._lan.listen='[::]:443 ssl'
uci add_list nginx._lan.listen="${EDGE_ROUTER}:443 ssl default_server"
uci add_list nginx._lan.listen="${EDGE_ROUTER}:80"
uci delete nginx._redirect2ssl
uci commit
echo "stream { include /usr/local/nginx/*.conf; }" >> /etc/nginx/uci.conf.template
/etc/init.d/nginx enable
```

## Format the SD Card
Create a single partition and format it as an ext4 filesystem.

```bash
wipefs -af /dev/mmcblk0
echo "/dev/mmcblk0p1 : start=1, type=83" > /tmp/part.info
sfdisk --no-reread -f /dev/mmcblk0 < /tmp/part.info
rm /tmp/part.info
mkfs.ext4 /dev/mmcblk0p1
```

## Mount the sdcard

```bash
mkdir -p /usr/local
PART_UUID=$(block info /dev/mmcblk0p1 | cut -d\" -f2)
MOUNT=$(uci add fstab mount)
uci set fstab.${MOUNT}.target=/usr/local
uci set fstab.${MOUNT}.uuid=${PART_UUID}
uci set fstab.${MOUNT}.enabled=1
uci commit fstab
block mount
# Make sure the sdcard is mounted
df
mkdir -p /usr/local/tftpboot/ipxe
mkdir /usr/local/tftpboot/networkboot
mkdir -p /usr/local/www/install
ln -s /usr/local/www/install /www/install
```

## Set up DNS

```bash
export EDGE_ROUTER=10.11.12.1
export EDGE_NETWORK=10.11.12.0
export EDGE_NETMASK=255.255.255.0
export EDGE_CIDR=24
export LAB_DOMAIN=my.awesome.lab
export ARPA=12.11.10

mkdir -p /usr/local/bind

cat << EOF > /usr/local/bind/named.conf
acl "trusted" {
 ${EDGE_NETWORK}/${EDGE_CIDR};
 127.0.0.1;
};

options {
 listen-on port 53 { 127.0.0.1; ${EDGE_ROUTER}; };
 
 directory  "/tmp";
 allow-query     { trusted; };
 allow-recursion { trusted; };
 recursion yes;

 forwarders {
   8.8.8.8;
   8.8.4.4;
  };
  auth-nxdomain no;

};

zone "${LAB_DOMAIN}" {
    type master;
    file "/usr/local/bind/db.${LAB_DOMAIN}"; # zone file path
};

zone "${ARPA}.in-addr.arpa" {
    type master;
    file "/usr/local/bind/db.${ARPA}";
};

zone "root" {
    type master;
    file "/etc/bind/db.root";
};
EOF

cat << EOF > /usr/local/bind/db.${LAB_DOMAIN}
@       IN      SOA     router.${LAB_DOMAIN}. admin.${LAB_DOMAIN}. (
             3          ; Serial
             604800     ; Refresh
              86400     ; Retry
            2419200     ; Expire
             604800 )   ; Negative Cache TTL
;
; name servers - NS records
    IN      NS     router.${LAB_DOMAIN}.

; name servers - A records
router.${LAB_DOMAIN}.         IN      A      ${EDGE_ROUTER}
EOF

cat << EOF > /usr/local/bind/db.${ARPA}
@       IN      SOA     router.${LAB_DOMAIN}. admin.${LAB_DOMAIN}. (
                            3         ; Serial
                        604800         ; Refresh
                        86400         ; Retry
                        2419200         ; Expire
                        604800 )       ; Negative Cache TTL

; name servers - NS records
    IN      NS      router.${LAB_DOMAIN}.

; PTR Records
1    IN      PTR     router.${LAB_DOMAIN}.
EOF
```

## Set up for SNO install

__Note:__ You will need a Pull Secret from Red Hat to perform this installation.

1. using your [https://developers.redhat.com](https://developers.redhat.com) account, log into [console.redhat.com/openshift/downloads](https://console.redhat.com/openshift/downloads).

1. Select `Tokens` from the drop down menu

1. Select `Copy` to the right of `Pull Secret`

1. Paste the content of your pull secret into a new file named `${OPENSHIFT_LAB_PATH}/lab-config/ocp-pull-secret`

1. On your local workstation - Linux or Mac OS ( Might also work with WSL2 on Windows)

```bash
mkdir -p ${HOME}/openshift-lab/bin
mkdir -p ${HOME}/openshift-lab/lab-config/{cluster-configs,lab-config-files,kubeconfigs}
WORK_DIR=$(mktemp -d)
git clone https://github.com/cgruver/kamarotos.git ${WORK_DIR}
cp -r ${WORK_DIR}/bin/* ${HOME}/openshift-lab/bin
chmod 700 ${HOME}/openshift-lab/bin/*
chmod 700 ${HOME}/openshift-lab/bin/modules/*
rm -rf ${WORK_DIR}

echo ". ${HOME}/openshift-lab/bin/labEnv.sh" >> ~/.bashrc
echo ". ${HOME}/openshift-lab/bin/labEnv.sh" >> ~/.zshrc
```

1. copy your public SSH key to the lab config folder so that you can access OpenShift nodes with SSH.

```bash
cp <PATH_TO_KEY>/<YOUR_SSH_KEY>.pub ${HOME}/openshift-lab/ssh_key.pub
```

1. Restart your shell to apply the changes.

1. Install `yq` we need this for manipulating YAML files:

Install instructions: [https://github.com/mikefarah/yq/#install](https://github.com/mikefarah/yq/#install)
Documentation: [https://github.com/mikefarah/yq](https://github.com/mikefarah/yq)

1. Create your lab configuration files:

```bash
cat << EOF > ${HOME}/openshift-lab/lab-config/lab.yaml
domain: my.awesome.lab
bridge:
  bridge-lan: 10.11.11.1
  bridge-netmask: 255.255.255.0
  router-wan-ip: 10.11.11.10
network: 10.11.12.0
router-lan-ip: 10.11.12.1
install-host: router
netmask: 255.255.255.0
sub-domain-configs: []
cluster-configs:
- name: sno-lab
  cluster-config-file: sno-dev.yaml
  domain: edge
EOF
```

You need three things at this point

1. The MAC address of the NIC on the machine that will run OpenShift
1. The path to the disk device that OpenShift will install on
1. The path to the disk that will be used to serve PVCs for workloads on your SNO cluster.

Find the path to the disks that you plan to use.  It will look something like `/dev/disk/by-path/pci-0000:02:00.0-nvme-1`

We need this path, because the actual `/dev/nvme0n1` that is available at runtime can drift depending on the parallel process that identifies the devices.

```bash
export BOOT_DEV=<path-to-your-boot-disk>
export PVC_DEV=<path-to-your-second-disk>
export BOOT_MAC=<your-device-mac-address>
```

1. Now create the cluster configuration file for a SNO install:

```yaml
cat << EOF > ${HOME}/openshift-lab/lab-config/cluster-configs/sno-dev.yaml
cluster:
  name: sno-dev
  cluster-cidr: 10.88.0.0/14
  service-cidr: 172.20.0.0/16
  remote-registry: quay.io/openshift-release-dev/ocp-release
  tools-uri: quay.io/openshift-release-dev/ocp-release
  butane-version: v0.29.0
  butane-variant: fcos
  butane-spec-version: 1.7.0
  release: 4.22.12-x86_64
  release-type: "ocp"
  disconnected: "false"
  nmstatectl-version: v2.2.55
control-plane:
  metal: true
  boot-dev: ${BOOT_DEV}
  hostpath-dev: ${PVC_DEV}
  nodes:
    - ip-addr: 10.11.12.80
      mac-addr: ${BOOt_MAC}
EOF
```

We are ready to install SNO on the device.

1. Set up the environment

```bash
labctx
```

press `1` and hit `<return>` or `<Enter>`

1. Setup the deployment artifacts and configuration:

```bash
labcli --deploy -c
```

1. Start the install:

```bash
labcli --start -c
```

1. Monitor install process:

```bash
labcli --monitor -b
```

1. If desired, watch the logs of the installing cluster.  Note: this command will fail if the node is still booting and `sshd` is not running yet.

```bash
labcli --monitor -m=0
```

Post Install:

1. Trust the cluster certs:

```bash
labcli --trust -c
```

1. Clean up the install left-overs:

```bash
labcli --post
```

1. Set up the PVC provisioner on the spare disk:

```bash
labcli --hostpath
```
